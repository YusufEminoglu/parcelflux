# Changelog

All notable changes to **ParcelFlux** are documented here.
Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) · versioning: [SemVer](https://semver.org/).

## [0.1.0] - 2026-05-28

- Initial dock-based release.
- Block-to-parcel subdivision with configurable width, min/max area.
- Single/double-row auto-detection.
- Row-width asymmetry for differentiated front/rear facades.
- Fishbone-style organic boundary offset.
- H-line shift for asymmetric depth.
- 3-pass residual fragment merging.
